Исходники: https://github.com/Cherishao/APT-Sample/tree/master/APT32

APT32 — группа, активная как минимум с 2012 года. По мнению различных исследователей, действует в интересах Вьетнама, специализируется на кибершпионаже в правительственных и корпоративных сетях стран Восточной и Юго-Восточной Азии.

Группа проводит целенаправленные операции по компрометации организаций через фишинг и поддельные установщики. Злоумышленники разворачивают многоступенчатые загрузчики и in-memory загрузчики (shellcode → PE), используют DLL-side-loading и другие техники уклонения, устанавливают backdoor-компоненты для удалённого управления, сбора файлов и перемещения по сети.

Для рассмотрения были выбраны следующие ВПО:

-        WinWord.exe

-        OceanLotusBackDoor.exe

-        Rastlsc.dll
