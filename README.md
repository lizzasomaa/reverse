В качестве аргументов она принимает указатель на функцию обратного вызова lpEnumFunc и параметр lParam, который передается lpEnumFunc. Видно, что в EnumWindows подаются sub_401790 и 0 соответственно.

##### TLS

TLS (Thread Local Storage) - локальная память потока, предназначенная для связки данных с потоком. При использовании статичной TLS появляется возможность выполнять произвольный код до передачи управления на точку входа. Это можно использовать для обнаружения отладчика еще до того, как он получит управление над программой.

Данная инструкция делает call на инструкцию с адресом на 5 байт больше собственного. Как видно, это следующая инструкция. При этом эта же инструкция является адресом возврата:
